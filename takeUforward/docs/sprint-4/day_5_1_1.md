## 1. Minimum Subarray Sum (Inverted Kadane)

Given an integer array `nums`, find the contiguous non-empty subarray with the smallest sum and return that sum.

### Example

```text
Input:  nums = [3, -4, 2, -3, -1, 7, -5]
Output: -6
Explanation: The subarray [-4, 2, -3, -1] has the smallest sum = -6.

Input:  nums = [2, 6, 8, 1, 4]
Output: 1
Explanation: The single element [1] has the minimum sum.

Input:  nums = [-1, -2, -3]  # Edge Case: All negative numbers
Output: -6
Explanation: The entire array [-1, -2, -3] has the minimum sum = -6.
```

### Think About

* **The Inverted Kadane Dual:**
  * In standard Kadane's algorithm, we discard negative prefix sums because they reduce a maximum sum.
  * Symmetrically, for **minimum subarray sum**, a positive prefix sum will only increase (hurt) any subsequent sum!
* **Algorithm Steps:**
  * Initialize `min_sum = float('inf')` and `current_sum = 0`.
  * For each number in `nums`:
    * Add `nums[i]` to `current_sum`.
    * Update `min_sum = min(min_sum, current_sum)`.
    * If `current_sum > 0`: reset `current_sum = 0` (discard the positive deficit).
* **Time Complexity:** $\mathcal{O}(N)$ — Single pass linear traversal.
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

## 2. Maximum Absolute Subarray Sum

Given an integer array `nums`, find the maximum absolute sum of any contiguous subarray. The absolute sum of a subarray $[nums[l], \dots, nums[r]]$ is defined as $|nums[l] + nums[l+1] + \dots + nums[r]|$.

### Example

```text
Input:  nums = [1, -3, 2, 3, -4]
Output: 5
Explanation: The subarray [2, 3] has sum = 5, with absolute value |5| = 5.

Input:  nums = [2, -5, 1, -4, 3, -2]
Output: 8
Explanation: The subarray [-5, 1, -4] has sum = -8, with absolute value |-8| = 8.

Input:  nums = [-10]  # Edge Case: Single negative element
Output: 10
Explanation: The subarray [-10] has absolute sum = 10.
```

### Think About

* **Dual Kadane Combination:**
  * The maximum absolute sum must come from one of two extremes:
    1. The greatest positive sum: standard **maximum subarray sum** (`max_sum`).
    2. The most negative sum: standard **minimum subarray sum** (`min_sum`).
  * The result is simply $\max(\text{max\_sum}, |\text{min\_sum}|)$.
* **Single-Pass Two-Track Kadane:**
  * Track both `cur_max` and `cur_min` simultaneously in a single loop:
    * `cur_max = max(num, cur_max + num)`
    * `cur_min = min(num, cur_min + num)`
    * `max_sum = max(max_sum, cur_max)`
    * `min_sum = min(min_sum, cur_min)`
  * Return `max(max_sum, abs(min_sum))`.
* **Time Complexity:** $\mathcal{O}(N)$ — Single pass through the array.
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

## 3. Maximum Subarray Sum with Length at Least K

Given an integer array `nums` and an integer `k`, find the maximum sum of a contiguous subarray that has a length of at least $k$.

### Example

```text
Input:  nums = [-4, -2, 1, -3], k = 2
Output: -1
Explanation: Subarray [-2, 1] has length 2 and maximum sum = -1.

Input:  nums = [1, 1, 1, 1, 1, 1], k = 3
Output: 6
Explanation: The whole array of length 6 (>= 3) has maximum sum = 6.

Input:  nums = [-1, 2, 3, -2, 5], k = 2  # Edge Case: Best length > k
Output: 8
Explanation: The subarray [2, 3, -2, 5] has length 4 (>= 2) with sum = 8.
```

### Think About

* **Sliding Window + Kadane Prefix:**
  * Any valid subarray of length $\ge k$ ending at index $i$ ($i \ge k - 1$) can be viewed as:
    $$\text{Exact window of size } k \text{ ending at } i + \text{an optional prefix ending at } (i - k)$$
  * To maximize this total sum, we should only include the prefix ending at $(i - k)$ if its maximum contiguous sum is positive!
  * That optimal prefix sum is precisely the standard Kadane sum ending at $(i - k)$.
* **Algorithm Steps:**
  * Compute the sum of the first $k$ elements (`window_sum`). Initialize `ans = window_sum`.
  * Track running Kadane prefix: `cur_kadane = 0`.
  * For $i$ from $k$ to $n - 1$:
    * Slide the window: `window_sum += nums[i] - nums[i - k]`.
    * Extend Kadane prefix with element `nums[i - k]`: `cur_kadane = max(nums[i - k], cur_kadane + nums[i - k])`.
    * Update: `ans = max(ans, window_sum, window_sum + cur_kadane)`.
* **Time Complexity:** $\mathcal{O}(N)$ — Single pass linear window.
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

## 4. Maximum Sum Circular Subarray (Amazon, Microsoft, Google)

Given a **circular** integer array `nums` of length $n$, find the maximum possible sum of a non-empty subarray. In a circular array, the end of the array wraps around to connect to the beginning.

### Example

```text
Input:  nums = [1, -2, 3, -2]
Output: 3
Explanation: Subarray [3] has maximum sum = 3 (no circular wrap needed).

Input:  nums = [5, -3, 5]
Output: 10
Explanation: Subarray [5, 5] wrapping from index 2 around to index 0 gives sum = 5 + 5 = 10.

Input:  nums = [-3, -2, -3]  # Edge Case: All negative numbers
Output: -2
Explanation: Subarray [-2] has maximum sum = -2. Circular wrap would produce an empty subarray.
```

### Think About

* **PBC Interview Classic (Amazon, Microsoft, Google):**
  * A circular maximum subarray can take one of two forms:
    1. **Non-wrapping subarray:** A standard linear contiguous subarray inside `nums`. Found directly with standard Kadane's: `max_sum`.
    2. **Wrapping subarray:** Takes elements from both the prefix and the suffix, leaving a contiguous subarray in the middle excluded.
  * To maximize the wrapping sum, we must **minimize** the excluded middle contiguous subarray!
    $$\text{circular\_max} = \text{total\_sum} - \text{min\_subarray\_sum}$$
    where `min_subarray_sum` is computed using Inverted Kadane.
* **Critical Edge Case (All Negative Elements):**
  * If all elements in `nums` are negative, `total_sum == min_subarray_sum`.
  * Subtracting would give `total_sum - min_subarray_sum == 0`, corresponding to an invalid empty subarray!
  * If `max_sum < 0`, all numbers are negative, so simply return `max_sum`.
  * Otherwise, return $\max(\text{max\_sum}, \text{total\_sum} - \text{min\_subarray\_sum})$.
* **Time Complexity:** $\mathcal{O}(N)$ — Single pass computing `total_sum`, `max_sum`, and `min_sum`.
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space.

## 5. Maximum Subarray Sum with at Most One Deletion (Google, Meta, Amazon)

Given an integer array `nums`, find the maximum sum of a non-empty subarray with **at most one** element deleted. You must choose at least one element.

### Example

```text
Input:  nums = [1, -2, 0, 3]
Output: 4
Explanation: Delete -2 to get the subarray [1, 0, 3] with sum = 4.

Input:  nums = [1, -2, -2, 3]
Output: 3
Explanation: Subarray [3] gives sum = 3 (no deletion needed).

Input:  nums = [-1, -1, -1, -1]  # Edge Case: All negative numbers
Output: -1
Explanation: You must pick at least one non-empty element; the maximum single element is -1.
```

### Think About

* **PBC Interview Follow-Up (Google, Meta):**
  * In standard Kadane's, a large negative number forces a reset. Here, we are allowed a one-time "free pass" to delete one detrimental negative value!
* **Two-State Kadane DP:**
  * For each position `i`, maintain two running values:
    1. `no_del`: maximum subarray sum ending at `i` with **0 deletions** (standard Kadane).
       $$\text{no\_del} = \max(nums[i], \text{no\_del} + nums[i])$$
    2. `one_del`: maximum subarray sum ending at `i` with **1 deletion**.
       * We could delete `nums[i]`: sum remains previous `no_del`.
       * Or we keep an earlier deletion and include `nums[i]`: `one_del + nums[i]`.
       $$\text{one\_del} = \max(\text{previous no\_del}, \text{one\_del} + nums[i])$$
  * Maintain global `ans = max(ans, no_del, one_del)`.
* **Alternative Forward & Backward Kadane:**
  * Precompute `max_ending_at[i]` using Kadane from left to right.
  * Precompute `max_starting_at[i]` using Kadane from right to left.
  * If deleting element `i`, the combined sum is `max_ending_at[i - 1] + max_starting_at[i + 1]`.
* **Time Complexity:** $\mathcal{O}(N)$ — Single pass traversal.
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space using scalar DP states.
